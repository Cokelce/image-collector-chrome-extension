# 图片收藏夹 Chrome 扩展

一个用于收藏全网图片和动态壁纸的 Chrome Manifest V3 扩展。它优先使用浏览器右键菜单保存图片/视频，减少对网页的全局注入，适合整理壁纸、插画、头像、设计灵感和动态壁纸。

## 功能

- 在任意网页图片或视频上右键收藏。
- 本地保存图片/动图到扩展 IndexedDB，站点防盗链失败时自动降级为仅保存原链接。
- 自动分析尺寸、色系、URL 关键词并做轻量分类。
- 毛玻璃弹窗 UI，6 列图库，支持搜索、分类筛选、类型/方向/来源/色系筛选。
- 图片卡片右键菜单：修改分类、下载、设为桌面壁纸、设为屏保、删除。
- Google Drive 云端同步：登录后自动上传到 Drive 云端文件夹。
- 备用 Google Drive 桌面文件夹同步：不使用 Drive API 时可手动启用。

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome，进入 `chrome://extensions`。
3. 打开右上角 `开发者模式`。
4. 点击 `加载已解压的扩展程序`。
5. 选择本项目目录，也就是包含 `manifest.json` 的文件夹。

加载后，在网页图片或视频上右键，选择 `收藏这个图片/动图`。

注意：Chrome 会根据“已解压扩展的本地路径”生成扩展 ID。不要频繁更换加载目录，否则新目录会被当成一个新插件，原 IndexedDB 收藏不会自动跟过去。建议固定加载 `C:\Program Files\CHAJIAN\chrome\chrome-extension` 或另一个长期不移动的目录。

## 使用

点击浏览器工具栏里的扩展图标，会打开收藏弹窗：

- 顶部搜索框可以按分类、标签、文件名、来源链接搜索。
- `全部 / 未分类 / 筛选` 用来过滤图片。
- 分类标签可横向滚动。
- 左键点击图片预览。
- 右键点击图片打开操作菜单。

## 导入和恢复

设置页的 `数据管理` 支持：

- `导出`：导出收藏元数据 JSON。
- `导入`：选择 JSON 后，扩展会重新下载可访问的原图/动图并写入当前插件数据库；已有链接会自动跳过。

如果移动扩展目录后发现收藏为空，优先回到原来的加载目录。若原数据库已经不可见，可以从之前导出的 JSON 或浏览器历史记录整理出的恢复 JSON 导入。

## Google Drive 云端同步

云端同步会直接通过 Google Drive API 上传到你的 Drive，不依赖本地 Google Drive 桌面文件夹。

同步目录结构：

```text
图片收藏夹/
├── 电脑壁纸/
└── 手机壁纸/
```

分流规则：

- 竖图保存到 `手机壁纸`
- 横图、方图、未知尺寸保存到 `电脑壁纸`
- 仅保存链接的记录会上传为 `.link.json`

### 获取 OAuth Client ID

Google Drive API 要求 OAuth 授权。`OAuth Client ID` 是公开应用 ID，不是密码，也不是客户端密钥。

1. 打开 [Google Cloud Console](https://console.cloud.google.com/)。
2. 新建或选择一个项目。
3. 进入 `API 和服务` -> `库`，搜索并启用 `Google Drive API`。
4. 进入 `API 和服务` -> `OAuth 同意屏幕`。
5. 选择 `外部`，填写应用名和邮箱。
6. 测试模式下，把自己的 Gmail 添加到 `测试用户`。
7. 进入 `API 和服务` -> `凭据`。
8. 点击 `创建凭据` -> `OAuth 客户端 ID`。
9. 应用类型选择 `Web 应用`。
10. 回到扩展设置页，复制 `回调地址`。
11. 把回调地址粘贴到 Google 的 `已获授权的重定向 URI`。
12. 创建后复制 `客户端 ID`，格式类似 `xxxxx.apps.googleusercontent.com`。
13. 粘贴到扩展设置页的 `OAuth Client ID` 输入框，点击 `保存`。
14. 点击 `登录 Drive`，授权后开启云端同步。

不要把 `客户端密钥` 填进扩展。这个扩展不需要客户端密钥。

## 隐私说明

- 默认只保存到本机浏览器扩展存储。
- Drive 云同步只有在你保存 OAuth Client ID 并登录 Drive 后才会上传。
- 图片上传到你自己的 Google Drive，扩展没有自建服务器。
- OAuth token 保存在浏览器本地扩展存储中。
- 清空数据会删除本机 IndexedDB 里的收藏记录，不会自动删除已经上传到 Drive 的文件。

## 开发验证

这个项目是无构建步骤的 Chrome 扩展，直接加载目录即可。

可用 Node 做基础语法检查：

```bash
npm run check
```

也可以手动打开：

```text
chrome://extensions
```

重新加载扩展后，在测试网页或真实网站图片上右键收藏。

## 目录结构

```text
analyzer/       图片基础分析、分类和关键词提取
background/     MV3 service worker，右键收藏、下载、Drive 同步
content/        可选页面注入能力，目前主流程不依赖
icons/          扩展图标
lib/            IndexedDB 封装
options/        设置页
popup/          弹窗图库 UI
test/           本地测试页面
```
